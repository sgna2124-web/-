# long_main v12 장단점

## 장점

1. 기준선 exact가 통과된 v18 결과에서 승격됐다.
   - v18의 첫 후보 `LM18_000_LONG_MAIN_V11_EXACT_FROZEN`이 v11 기준선을 완전 재현했다.
   - 그 위에서 `LM18_041_STOP115_RR520_BODY025`가 1위를 기록했다.

2. cd_value 개선폭이 크다.
   - v11: 453.60741100633686
   - v12: 491.134662921777
   - 개선폭: +37.52725191544014

3. wins/losses 구조가 좋아졌다.
   - wins: 20168 -> 20531
   - losses: 36483 -> 35897
   - RR만 올린 v17 1위와 달리 거래 구조도 개선됐다.

4. body_atr 필터의 효과가 명확하다.
   - `atr_stop=1.15`, `rr_target=5.20` 단독보다 `body_atr >= 0.25`를 붙인 후보가 더 좋았다.

5. MDD가 여전히 낮다.
   - max_drawdown_pct: 1.4367182391297861
   - long_main 기준인 5% 미만을 충분히 만족한다.

## 단점

1. MDD는 v11보다 증가했다.
   - v11: 1.2516306589841375
   - v12: 1.4367182391297861

2. max_conc가 443으로 1 증가했다.
   - 다종목 동시 진입 부담은 여전히 크다.

3. rr_target 5.20은 목표가 긴 편이다.
   - 실거래에서는 슬리피지, 순간 고가 체결, 미체결, 거래소 API 반응 지연 영향이 커질 수 있다.

4. TP03 gate 재계산 실수 위험이 있다.
   - entry source는 rr_target 3.80 기준 TP03이다.
   - 최종 exit는 rr_target 5.20이다.
   - 이 둘을 혼동하면 재현이 깨진다.

## 다음 개선 방향

1. LM18_041과 LM18_042 절충 검증
   - LM18_042는 cd가 약간 낮지만 MDD와 losses가 더 낮았다.
   - vol_ratio 1.10, 1.15, 1.20, 1.25 구간을 비교한다.

2. body_atr 근처값 비교
   - body_atr 0.20, 0.25, 0.30을 비교한다.

3. max_hold 증가는 제외 우선
   - v18에서 hold 24/27 조합은 성과가 크게 떨어졌다.

4. close_pos >= 0.70은 제외 우선
   - 거래 수가 급감하고 cd_value가 크게 낮아졌다.

5. 2026년 검증
   - v12는 2025년까지의 기준선이다.
   - 2026년 구간은 별도 검증 세트로 사용한다.
