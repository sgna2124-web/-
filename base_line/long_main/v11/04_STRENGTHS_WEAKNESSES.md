# long_main v11 장단점

## 장점

1. 기준선 exact가 먼저 통과된 상태에서 나온 개선이다.
   - v15에서 기존 v10 기준선 `LM15_000_LONG_MAIN_V10_EXACT_FROZEN`이 공식값을 완전 재현했다.
   - 그 위에서 `LM15_031_V10_RR420`이 1위를 기록했다.

2. cd_value 개선폭이 크다.
   - v10: 426.96146593036525
   - v11: 453.60741100633686
   - 개선폭: +26.64594507597161

3. MDD가 오히려 낮아졌다.
   - v10: 1.2943172013524573
   - v11: 1.2516306589841375
   - long_main 기준인 MDD 5% 미만을 충분히 만족한다.

4. 진입 조건을 건드리지 않았다.
   - 기준선 entry `child::orig_V09_extreme_vol18::tp03`를 그대로 유지했다.
   - 개선 요인은 `rr_target 3.80 -> 4.20`이다.
   - 따라서 진입 조건 복원 리스크가 작다.

5. 2025년까지의 데이터 기준으로 명확히 분리됐다.
   - `train_end_exclusive_utc = 2026-01-01 00:00:00`
   - 2026년 데이터는 검증용으로 남긴다.

## 단점

1. 승률은 v10보다 낮아졌다.
   - v10: 35.740123162705345%
   - v11: 35.600430707313194%

2. wins/losses 구조는 약간 나빠졌다.
   - wins: 20255 -> 20168
   - losses: 36418 -> 36483

3. rr_target이 높아진 만큼 체결 민감도가 커질 수 있다.
   - 목표 수익폭이 커지면 실거래에서 슬리피지, 순간 고가 체결, 미체결 이슈가 더 중요해질 수 있다.

4. max_conc는 여전히 높다.
   - max_conc: 442
   - 다종목 동시 진입 부담이 크다.

5. 이번 개선은 진입 품질 개선이 아니다.
   - 진입 조건은 유지되고 청산 목표만 확장된 구조다.
   - 다음 개선에서는 진입 필터, 동시성 제어, 방어형 조건을 따로 검증할 필요가 있다.

## 다음 개선 방향

1. rr_target 추가 상향 검증
   - 4.30, 4.40, 4.50 등은 가능하지만 과최적화 위험이 있으므로 단독 리테스트 필수.

2. body/volume 필터 재검증
   - 이전 body_atr >= 0.25 계열은 기준선에서 꾸준히 소폭 개선을 냈다.
   - 단, rr 4.20 기준에서도 동일하게 작동하는지 재검증해야 한다.

3. MDD 방어형 후보 검증
   - cd_value 1위와 별도로 MDD를 낮추는 후보도 기록한다.

4. 2026년 검증
   - v11은 2025년까지의 기준선이다.
   - 2026년 구간은 별도 검증 세트로 사용한다.
