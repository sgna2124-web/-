# LONG_MAX 연구 로그 인덱스

이 폴더는 long_max 개발 대화창의 누적 실험 기록을 보관한다.

목적:
- 다음 대화창에서 이미 실패한 개선 방식을 반복하지 않도록 한다.
- 기준선 갱신 문서와 실험 로그를 분리한다.
- long_max 개발 과정에서 시도한 철학, 조건, 결과, 배제 사유를 누적한다.

운영 원칙:
- 실험 1개 또는 철학 전환 1개당 기록 파일 1개를 추가한다.
- 기존 기록을 덮어쓰지 않는다.
- 파일명은 버전과 핵심 주제를 포함한다.
- 결과 폴더가 있으면 해당 local_results 경로를 반드시 적는다.
- 다음 대화창의 새로운 담당자가 이 폴더부터 읽으면 된다.

현재 핵심 결론:
- long_max 최상위는 현재까지 반등형 엔진이다.
- trend acceleration / breakout continuation long은 실패했다.
- trend pullback / reclaim long도 실패했다.
- long은 short처럼 추세 지속형으로 잘 먹히지 않는다.
- 다음 유망 방향은 기존 반등형 진입 유지 + exit 구조 개선이다.
